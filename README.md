# Hunting Log Helper (hlh)

A Dalamud plugin that works through your class hunting log: it picks the incomplete target nearest your level, travels there, finds the mob, lets BossMod Reborn and Rotation Solver Reborn fight, checks that the log entry is complete, and moves on.

- Setup and install: [docs/SETUP.md](docs/SETUP.md)
- How the code is organized: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)

Personal tool. Automation breaks the FFXIV terms of service; use at your own risk.
